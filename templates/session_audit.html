Panduan Teori & Mitigasi Session Hijacking untuk Mahasiswa
1. Cookie Secure Flags:
  • HttpOnly: Mencegah JavaScript (XSS) membaca cookie.
  • Secure: Memastikan cookie hanya ditransmisikan lewat HTTPS terenkripsi.
  • SameSite=Strict/Lax: Menangkal serangan Cross-Site Request Forgery (CSRF).
2. Session Fixation & Regeneration:

Aplikasi web wajib menghasilkan token sesi baru (*regenerate session ID*) segera setelah pengguna berhasil login, agar penyerang tidak dapat memaksakan (*fixate*) token yang telah disiapkan sebelumnya.

3. Session Binding & Monitoring:

Sistem harus memvalidasi kesesuaian IP / fingerprint perangkat pada setiap permintaan. Jika token yang sama tiba-tiba muncul dari IP atau User-Agent yang berlainan, sesi harus segera di-invalidasi (*forced re-login*).
